# «Ертегілер әлемі 2.0» — Netlify starter v2

Бұл пакет пайдаланушы жүктеген **«Ерте заманда Ерназар деген кісі болыпты.pdf»** файлының 16 бетін оқып, соның негізінде құрылымдалған білім қорын қосады. Бұрынғы 3D-монополия сайтын өзгертпейді.

## Құрамы
- `index.html` — чат интерфейсі; серверге `/.netlify/functions/chat` арқылы сұрау жібереді.
- `netlify/functions/chat.mjs` — серверлік ЖИ функциясы.
- `netlify/functions/story-knowledge.mjs` — осы PDF мәтінінен жасалған кейіпкерлер, оқиға кезеңдері және 10 тексеру сұрағы.
- `netlify.toml` — Netlify конфигурациясы.

## Netlify баптауы
Netlify → Site configuration → Environment variables:
- `OPENAI_API_KEY` — OpenAI API кілті.
- `OPENAI_MODEL` — API аккаунтыңызда қолжетімді нақты модель идентификаторы.

Бұл пакет әдейі модель идентификаторын болжап қоймайды. Қолжетімді модельді API аккаунтыңыздан тексеріп, айнымалыға өзіңіз орнатыңыз.

## Жариялау
1. ZIP-ті ашыңыз.
2. Файлдарды жаңа GitHub репозиторийіне жүктеңіз немесе Netlify-де жаңа сайт ретінде импорттаңыз.
3. Жоғарыдағы екі environment variable-ды орнатыңыз.
4. Deploy жасаңыз.

## Қауіпсіздік және шектеулер
- API кілтін браузерге, `index.html` файлына немесе Git репозиторийіне жазбаңыз.
- Бала оқушыдан аты-жөні, телефоны, мекенжайы, мектебі сияқты деректерді сұрамау туралы нұсқау енгізілген.
- Чат тарихы серверде сақталмайды; соңғы 10 хабар браузерден сұрау сайын жіберіледі.
- Бұл бастапқы прототип. Қоғамдық пайдалануға берер алдында rate limiting, abuse қорғанысы, құпиялылық ескертуі және мұғалім бақылауы қосылуы керек.
- Жүктелген PDF мәтінінің осы шығарылымдағы үзінділері білім қорына қысқаша құрылымдалды; қажет болса келесі кезеңде толық мәтінді бөліктерге бөліп іздеу (RAG) тәсілімен қосуға болады.
- Сюжеттік деректер пайдаланушы жүктеген осы нұсқаға ғана сүйенеді; өзге басылымдардағы айырмашылықтар автоматты түрде қосылмаған.

## Квест модулі (жаңа)
- `quest.html` — 6-сыныпқа арналған 8 кезеңдік интерактивті квест.
- Әр кезеңде 2 тапсырма бар (барлығы 16); жауапты тексеру, түсіндірме кері байланыс, қайта жауап беру, +10 ұпай және кезеңді ашу механикасы жұмыс істейді.
- Ойын барысы браузердің `localStorage` жадында осы құрылғыда сақталады; серверге оқушының жеке деректері жіберілмейді.
- `index.html` басты бетіне «Квестті бастау» сілтемесі қосылды. Бұрынғы 3D-монополия сайтына өзгеріс енгізілмейді.
- Сюжеттік тапсырмалар жүктелген 16 беттік PDF мәтініне ғана негізделген. Басқа нұсқалардан дерек қосылмаған.
